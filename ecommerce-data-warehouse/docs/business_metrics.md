# ShopEasy 电商数据仓库 — 业务指标定义

## 核心指标 (KPIs)

### 1. GMV (Gross Merchandise Volume) — 总交易额
- **定义**: 统计周期内所有有效订单的实付金额总和
- **公式**: `SUM(actual_amount) WHERE order_valid_flag = '有效'`
- **口径**: 不含已取消和已退款订单
- **货币**: 人民币 (¥)

### 2. AOV (Average Order Value) — 平均客单价
- **定义**: 每笔有效订单的平均实付金额
- **公式**: `GMV / 有效订单数`
- **用途**: 衡量用户单次消费水平

### 3. 有效订单数
- **定义**: 统计周期内除"已取消"和"已退款"外的订单数
- **公式**: `COUNT(DISTINCT order_id) WHERE order_status NOT IN ('已取消', '已退款')`

### 4. 下单用户数 (Unique Buyers)
- **定义**: 统计周期内至少下了一笔有效订单的去重用户数
- **公式**: `COUNT(DISTINCT user_id) WHERE order_valid_flag = '有效'`

### 5. 人均订单数 (Orders Per User)
- **定义**: 平均每个下单用户的有效订单数
- **公式**: `有效订单数 / 下单用户数`

## 用户指标

### 6. 用户留存率 (Retention Rate)
- **定义**: 在注册后第 N 周仍有购买行为的用户占该周期注册用户的比例
- **公式**: `第N周活跃用户数 / 同期注册用户数`
- **周期**: 按注册周划分 Cohort

### 7. ARPU (Average Revenue Per User)
- **定义**: 平均每个用户的消费金额
- **公式**: `GMV / 下单用户数`

### 8. 复购率
- **定义**: 购买 ≥2 次的用户占比
- **公式**: `购买次数≥2的用户数 / 总下单用户数`

### 9. RFM 分层
- **R (Recency)**: 距最近一次购买的天数
- **F (Frequency)**: 累计购买次数
- **M (Monetary)**: 累计消费金额
- **分层方法**: NTILE(5) 三等分后组合，共7个标签

## 商品指标

### 10. 品类市场份额
- **定义**: 某品类下某品牌的销售额占该品类总销售额的比例
- **公式**: `品牌销售额 / 品类总销售额`

### 11. 毛利率 (Gross Margin)
- **定义**: 商品售价与成本之间的差额比例
- **公式**: `(unit_price - cost_price) / unit_price`

### 12. 动销商品数
- **定义**: 统计周期内至少被购买一次的商品数
- **公式**: `COUNT(DISTINCT product_id) WHERE 有订单`

---

## 增长指标

### 13. 环比增长率 (MoM Growth)
- **定义**: 本月与上月的指标对比
- **公式**: `(本月值 - 上月值) / 上月值`

### 14. 同比增长率 (YoY Growth)
- **定义**: 本月与去年同月的指标对比
- **公式**: `(本月值 - 去年同月值) / 去年同月值`

### 15. 折扣率
- **定义**: 折扣金额占原价金额的比例
- **公式**: `SUM(discount) / SUM(order_amount)`
